FRB Order Monitor helps its operator prepare marketplace orders for picking. It runs on the operator’s Windows computer, not on this website.

What the application does

The application uses the Gmail API to read order-related messages in the operator’s authorized mailbox. Recognized notifications from eBay, Poshmark, and Depop supply local order and status evidence. Existing read-only eBay order synchronization can confirm eBay order details.

Supported records update a shared local Pick List. Messages without enough exact order or item identity remain available for review rather than being matched by title alone.

Access stays read-only

The Gmail permission requested is gmail.readonly. The monitor does not send, delete, archive, label, or mark messages as read. It does not publish or delist marketplace listings, mark shipments, or change physical inventory. Vendoo separately handles cross-marketplace delisting.

Not a public email service

This application is used privately by its operator. This informational website has no sign-in, mailbox connection, order lookup, analytics scripts, or application database.
