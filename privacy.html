Privacy Policy

FRB Order Monitor is a private, single-user desktop application. This policy describes that application and its separate informational website.

Google data accessed and purpose

The operator authorizes the desktop application to access Gmail using the read-only Gmail API scope. That scope can read the authorized mailbox. The application’s monitoring workflow searches for marketplace sale and subsequent order-status notifications and reads the selected messages’ headers and bodies to identify supported order facts.

This access is used to prepare a local Pick List and retain order, payment, fulfillment, cancellation, and refund evidence. Gmail authentication is checked against the configured orders mailbox before messages are read.

Local storage and retention

Message bodies are processed transiently. The monitor’s business ledger retains minimized facts such as Gmail message identifiers, marketplace and order identifiers, exact item or SKU mappings when available, quantities, timestamps, and status or review reasons. It does not retain full email bodies, shipping addresses, telephone numbers, payment instrument details, or downloaded shipping-label attachments.

OAuth tokens are stored locally using Windows current-user encryption. Local evidence and backups remain on the operator’s computer until the operator removes them. There is no automatic expiration of that local business evidence.

Use and sharing restrictions

The standalone monitor does not send message contents to AI services, use Google user data for advertising or AI-model training, sell Google user data, or upload it to this public website or its source repository. It makes authenticated requests to Google to read Gmail; supported eBay notifications can invoke a separate read-only eBay order synchronization. No Gmail bodies or OAuth credentials are supplied to eBay.

FRB Order Monitor’s use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including its Limited Use requirements.

Operator controls

The operator may stop or disable the scheduled Windows task at any time and revoke the application’s access using Google Account connections. Revocation prevents future authorized reads but does not erase previously saved local evidence or backups. The operator controls those local files separately.

This website

The static website does not connect to Gmail, accept uploaded order data, use analytics scripts, or set application cookies. GitHub Pages provides its hosting and may process visitor connection information under GitHub’s Privacy Statement. The desktop application is not hosted by GitHub Pages.

Contact and changes

The application operator maintains this policy through the Avodado GitHub account. Do not post email contents, credentials, or order/customer details publicly. Changes to the application’s data practices will be reflected in this policy’s update date.
